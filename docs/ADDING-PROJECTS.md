# Cómo añadir un proyecto real

1. Abre `projects-en.html`, `projects-es.html` y `projects-sv.html`.
2. Copia un bloque completo `<article class="project-card">` o completa la ficha pendiente de Tryssen.
3. Cambia el nombre y la descripción en cada idioma. Incluye únicamente tecnologías que hayas usado.
4. Guarda una captura real en `assets/` y sustituye el bloque `project-placeholder` por una imagen dentro de `project-media`, como en la tarjeta del portfolio. Añade un texto `alt` que describa la captura si aporta información nueva.
5. Añade enlaces a la web y al repositorio solo cuando estén disponibles. No uses `href="#"` para simular enlaces pendientes.
6. Comprueba que ambos enlaces funcionan y que el texto cabe en móvil. No hace falta cambiar el CSS.

`project-copy` contiene el texto, `technology-list` las tecnologías y `actions` los enlaces. La ficha de Tryssen se mantiene claramente provisional hasta confirmar su información.
